# LaTeX Blocks brand assets

`latex-blocks-icon.png` is the canonical 1024 × 1024 transparent product mark.
Its visible artwork reaches every canvas edge; do not add baked-in transparent
padding. Layouts that require breathing room should provide it outside the image.

The numbered PNG files are application-ready raster sizes. The multi-resolution
ICO is used by the Windows installer, uninstaller, and About dialogs. Derive new
sizes from the canonical PNG so all product surfaces retain the same artwork.
